# Arithmetic and Comparative Operations in Python

A deep dive into Python's mathematical and comparison operators for performing calculations and evaluating conditions.

## What I Learned

### Arithmetic Operations
- **Addition (+)** – Summing values and concatenation
- **Subtraction (-)** – Finding differences between values
- **Multiplication (*)** – Repeating values and scaling
- **Division (/)** – True division returning float results
- **Floor Division (//)** – Integer division discarding remainders
- **Modulus (%)** – Finding remainders for divisibility checks
- **Exponentiation (**)** – Raising numbers to powers
- Operator precedence and order of operations

### Comparative Operations
- **Equal to (==)** – Checking if values are identical
- **Not equal to (!=)** – Checking if values differ
- **Greater than (>)** – Checking if value exceeds another
- **Less than (<)** – Checking if value is below another
- **Greater than or equal to (>=)** – Inclusive upper bound check
- **Less than or equal to (<=)** – Inclusive lower bound check
- Comparing numeric values, strings, and other data types

## Key Skills Acquired

- Performing complex mathematical calculations in Python
- Building conditional logic using comparative operators
- Creating decision-making structures with if statements
- Understanding operator precedence for accurate results
- Combining arithmetic and comparative operations in expressions
